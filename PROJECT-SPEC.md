# Todo App — Project Specification

## Project Name

Todo App

## Objective

The goal of this project is to create a simple web application that allows users to manage their daily tasks.

## Target Users

Anyone who wants a simple way to create and manage a list of tasks.

## Technologies

* HTML
* CSS
* JavaScript
* localStorage

## Core Features

1. Users can add new tasks.
2. Users can add tasks by pressing the Enter key.
3. Users can mark tasks as completed.
4. Users can delete tasks.
5. Tasks are stored in the browser using localStorage.
6. Tasks remain available after refreshing the page.

## User Interface

The application will contain:

* A page title
* A text input for entering tasks
* An Add Task button
* A list displaying tasks
* A Delete button for each task

## Deployment

The project will be stored on GitHub and deployed using GitHub Pages.

## Expected Result

A functional and responsive Todo application that users can access through a web browser.
