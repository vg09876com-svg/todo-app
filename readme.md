# Todo App

A simple and responsive Todo application built with HTML, CSS, and JavaScript.

## Project Description

The Todo App allows users to create and manage their daily tasks directly in the browser.

Users can add new tasks, mark tasks as completed, delete tasks, and keep their tasks saved even after refreshing the page.

## Features

* Add a new task
* Add tasks using the Enter key
* Mark tasks as completed
* Delete tasks
* Save tasks using localStorage
* Tasks remain after refreshing the browser
* Responsive and simple user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser localStorage

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start adding and managing your tasks.
