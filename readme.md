# Todo App

A simple and responsive Todo application built with HTML, CSS, and JavaScript.

## Project Description

The Todo App allows users to create and manage their daily tasks directly in the browser.

Users can add new tasks, mark tasks as completed, delete tasks, and keep their tasks saved even after refreshing the page.

## Features

* Add a new task
* Add tasks using the Enter key
* Mark tasks as completed
* Delete tasks
* Save tasks using browser localStorage
* Tasks remain after refreshing the browser
* Responsive and simple user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser localStorage

## How to Run the Project

1. Clone the repository from GitHub.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start adding and managing your tasks.

## How to Use the App

### Add a Task

Type a task into the input field and click the **Add Task** button.

You can also press the **Enter** key on your keyboard to add a task.

### Complete a Task

Click on a task to mark it as completed.

### Delete a Task

Click the **Delete** button beside a task to remove it.

### Save Tasks

The application uses browser `localStorage` to save tasks. This means your tasks remain available even after refreshing the page.
